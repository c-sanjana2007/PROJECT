# PROJECT
# Retail Sales Performance Dashboard

## Project Overview

This project focuses on analyzing retail sales data and transforming
raw transactional data into meaningful business insights through
an interactive dashboard.

The dataset contains 4,280 retail orders with information about
customers, products, sales, profit, payment methods, shipping and
order status.

## Objectives

- Analyze overall sales and profit performance
- Identify top-performing regions and cities
- Understand customer payment preferences
- Analyze order fulfillment and return status
- Evaluate shipping performance
- Identify monthly sales trends
- Analyze year-wise revenue performance

## Key Metrics

- Total Orders: 4,280
- Total Sales: ₹266.89M
- Total Profit: ₹50.02M
- Total Quantity Sold: 31,324
- Average Shipping Time: 5.63 days

## Analysis Performed

1. Regional Sales & Profit Analysis
2. Payment Method Analysis
3. Shipping Performance Analysis
4. Order Status Analysis
5. Top Cities Analysis
6. Monthly Sales Analysis
7. Year-wise Revenue Analysis

## Key Insights

- South was the highest-performing region by sales.
- Kochi generated the highest city-wise sales.
- UPI was the most frequently used payment method.
- Electronics had the highest average shipping time.
- January recorded the highest monthly sales.
- 2023 recorded the highest yearly sales.
- Most orders were successfully delivered.

## Business Value

The dashboard provides a quick overview of retail performance and
helps identify high-performing regions and cities, customer payment
preferences, shipping issues, order fulfillment patterns and sales trends.
